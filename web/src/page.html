Баны

Клик по герою добавляет его в выбранную группу, правый клик открывает карточку. Клик по слоту убирает героя. В поиске Enter добавляет первого найденного, Tab переключает группу. Кнопка «⇄ Сравнить» (или Shift+клик по двум героям) открывает сравнение пары.
