# Dota 2 Draft Helper

Оверлей для Windows, который во время драфта показывает по каждому герою:

- **напарников на линии** (кто чаще выигрывает линию вместе с ним),
- **союзников в матче** (синергия в одной команде),
- **кого он контрит** и **кто контрит его**,

а также подсказывает, кого взять и кого забанить по уже выбранным героям.

## Запуск

Готовая сборка: `Dota2-Draft-Helper-0.1.0.exe` (портативная, установка не нужна). Файл не подписан, поэтому Windows SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

Из исходников (нужен Node.js 20+):

```
npm install
npm start          # запуск
npm test           # тесты логики
npm run dist:win   # собрать .exe в dist/
```

## Как пользоваться

1. В Dota 2 включите режим экрана **«Оконный без рамки» (Borderless window)**. В эксклюзивном полноэкранном режиме ни один оверлей не виден поверх игры.
2. `Alt+Shift+D` показывает и скрывает окно, `Alt+Shift+C` включает режим, при котором клики проходят сквозь окно в игру. Клавиши меняются в настройках (⚙).
3. Выберите группу (**Мы / Враги / Бан**, переключение клавишей Tab), набирайте имя героя и жмите Enter, либо кликайте по иконкам. Клик по слоту убирает героя, правый клик по любому герою открывает его карточку.
4. Во вкладке «Подсказки» список «Кого взять» считается как сумма преимуществ против каждого врага и синергии с каждым союзником; «Кого забанить» показывает героев, которые сильнее всего против вашей команды.

## Откуда данные

- **STRATZ API** (рекомендуется): контрпики, синергия и исходы линий, с фильтром по рангу. Нужен бесплатный токен: войдите через Steam на https://stratz.com/api и вставьте токен в настройках.
- **OpenDota API** (без ключа): только контрпики, без разбивки по рангу. Используется, если токена нет или STRATZ не ответил. Первая загрузка занимает около 2–3 минут из-за лимита 60 запросов в минуту.

Статистика кэшируется на диске и обновляется раз в сутки (или кнопкой ⟳).

Все проценты показывают отклонение от ожидаемого: например, «+3%» в «Кого контрит» значит, что герой выигрывает у этого соперника на 3 п.п. чаще, чем предсказывают их общие винрейты. Маленькие выборки ужимаются к нулю, чтобы случайные 10 игр не попадали в топ.

## Структура

- `main.js`: окно поверх игры, горячие клавиши, настройки.
- `src/data.js`: загрузка и кэш статистики STRATZ/OpenDota.
- `src/scoring.js`: расчёт контрпиков, синергии и подсказок.
- `renderer/`: интерфейс.
- `test/`: тесты (`npm test`).
