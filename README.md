# Dota 2 Draft Helper

Помощник для драфта Dota 2. Для каждого героя показывает напарников на линии, союзников в матче, кого он контрит и кто контрит его, а по текущему драфту подсказывает, кого взять и кого забанить.

- `index.html`: готовый сайт (GitHub Pages), собирается из `web/` командой `python3 web/build.py` и копированием `web/dist/index.html` в корень.
- `web/`: исходники сайта. Статистика загружается прямо из браузера: STRATZ (с бесплатным токеном, синергия и линии) или OpenDota (без ключа, только контрпики), кэш на сутки.
- `desktop/`: версия-оверлей для Windows на Electron (см. `desktop/README.md`).
